# ТЗ: qBit — альтернативный WebUI для qBittorrent

Nov 1, 2026 · @Evan

## Обзор

qBit — статический альтернативный WebUI для qBittorrent: современный минималистичный интерфейс в тёмной теме, для десктопа и телефона. Его раздаёт сам qBittorrent через опцию «Использовать альтернативный WebUI», своего бэкенда нет — всё работает через стандартный WebAPI.

**Цели**

- Заменить стандартный интерфейс qBittorrent на быстрый и аккуратный, по готовым макетам (раздел «Дизайн-система»).
- Покрыть всё, что нужно в повседневной работе: список, фильтры, добавление, пауза и удаление, детали торрента, приоритеты, лимиты скорости, настройки, вход.
- Полноценная мобильная версия, а не ужатый десктоп.

**Что НЕ делаем** (в отличие от qui)

- Несколько инстансов qBittorrent, cross-seed, автоматизации и правила.
- Собственный сервер, базу данных, многопользовательский режим.
- RSS и поисковые плагины — не в первой версии.
- Светлую тему — не в первой версии.

**Целевые версии.** qBittorrent 5.x (WebAPI 2.11+), без обратной совместимости с 4.x — на старых версиях WebUI показывает сообщение о версии (раздел «Работа с WebAPI»).

## Стек и сборка

SPA на React + TypeScript, собирается Vite в папку, которую qBittorrent раздаёт как альтернативный WebUI.

| Задача | Решение |
| --- | --- |
| Сборка | Vite, `base: './'` (относительные пути) |
| UI | React 18+, TypeScript strict |
| Стили | CSS-переменные для токенов + Tailwind или CSS Modules — на выбор исполнителя |
| Состояние | Zustand: стор торрентов, который сливает инкрементальные ответы `sync/maindata` |
| Запросы | Свой тонкий клиент на `fetch` поверх `/api/v2` |
| Роутинг | Hash-роутинг (`#/settings`) — qBittorrent не отдаёт index.html на произвольные пути |
| Иконки | lucide-react (тот же штриховой стиль, что в макетах) |
| Шрифты | Inter 400/500/600 и JetBrains Mono 400/500 через @fontsource, лежат в бандле |
| Флаги | Пакет flag-icons (SVG), лежит в бандле |
| Длинные списки | TanStack Virtual |
| Разбор .torrent | Небольшой bencode-парсер в браузере (имя, размер, файлы, infohash) |

**Никаких внешних запросов в рантайме**: шрифты, флаги и иконки только локально. qBittorrent может отдавать заголовок CSP, который режет внешние источники, а WebUI часто открывают без интернета.

**Результат сборки** — папка `qbit/` с подпапкой `public/` (`index.html` и ассеты), как у VueTorrent. Всё лежит в `public`: qBittorrent отдаёт эту папку без авторизации, а вход SPA делает само через API. Корень альтернативного WebUI — папка `qbit`, а не `public`.

**Структура исходников**

- `src/api/` — клиент, типы ответов WebAPI, определение версии API
- `src/store/` — стор торрентов, выбор, настройки интерфейса
- `src/features/` — `torrents`, `details`, `add`, `limits`, `settings`, `auth`
- `src/components/ui/` — кнопки, поля, тумблеры, чекбоксы, табы, диалоги, прогресс
- `src/styles/tokens.css` — все токены из раздела «Дизайн-система»

### Сборка и релизы на GitHub

Всё собирает GitHub Actions; локально нужен только `npm run dev`. Схема повторяет VueTorrent: архив в релизе, ветка `latest-release` и Docker mod.

| Workflow | Когда | Что делает |
| --- | --- | --- |
| `ci.yml` | push и pull request | `npm ci`, проверка типов, линтер, `npm run build` |
| `release.yml` | тег `v*` (например `v1.2.0`) | сборка → `qbit.zip` (внутри `qbit/public/…`) → GitHub Release с changelog и архивом |
| тот же `release.yml` | после релиза | содержимое `qbit/` в ветку `latest-release` (force-push, ветка без истории сборок) |
| тот же `release.yml` | после релиза | Docker mod в GHCR: `ghcr.io/<owner>/qbit-mod:latest` и `:1.2.0` |

- **Docker mod** — образ для [Docker mods linuxserver](https://github.com/linuxserver/docker-mods): `Dockerfile.mod` из `FROM scratch` и `COPY qbit /qbit`. При старте контейнера linuxserver копирует файлы мода в контейнер, и WebUI оказывается в `/qbit`. Пушится через `docker/build-push-action` с `GITHUB_TOKEN` (`permissions: packages: write`), образ публичный.
- **Версия** берётся из тега и вшивается при сборке (`define: { __APP_VERSION__ }`); показывается на экране входа и в настройках.
- Changelog — из коммитов по Conventional Commits (например, release-please или git-cliff).
- В README — бейджи CI и последнего релиза, три способа установки из раздела «Подключение», обновление и откат.

## Подключение к qBittorrent в Docker

Подключается так же, как VueTorrent: одним из трёх способов, без пересборки образа qBittorrent. Во всех случаях в qBittorrent включается «Использовать альтернативный WebUI» с путём к папке `qbit` (той, в которой лежит `public`).

1. **Docker mod** (для `lscr.io/linuxserver/qbittorrent`) — основной способ. Добавить переменную и пересоздать контейнер:

   ```yaml
   environment:
     - DOCKER_MODS=ghcr.io/<owner>/qbit-mod:latest
   ```

   Путь альтернативного WebUI — `/qbit`. Обновление — пересоздать контейнер (`docker compose up -d --force-recreate`); закрепить версию — тег вместо `latest`.
2. **Архив из релиза** — для любого образа (hotio, официальный и т.д.). Скачать `qbit.zip` со страницы релиза, распаковать на хосте и примонтировать:

   ```yaml
   volumes:
     - ./qbit:/qbit:ro
   ```

   Путь — `/qbit`. Обновление — заменить содержимое папки и обновить страницу.
3. **Git** — для удобного обновления без скачивания архивов:

   ```sh
   git clone --single-branch -b latest-release https://github.com/<owner>/qbit ./qbit
   ```

   Монтирование и путь — как во втором способе; обновление — `git -C ./qbit pull`.

То же через `qBittorrent.conf`: `WebUI\AlternativeUIEnabled=true`, `WebUI\RootFolder=/qbit`.

**Разработка.** Vite dev-сервер проксирует `/api` на настоящий qBittorrent (адрес из `.env`, например `QBIT_URL=http://nas.local:8080`). У qBittorrent включена защита от CSRF и проверка заголовка Host: прокси должен подменять `Origin`, `Referer` и `Host` на адрес qBittorrent, иначе запросы получат 401/403. Отключать эти защиты в qBittorrent не нужно.

**Откат.** Снять галку «Использовать альтернативный WebUI» — вернётся стандартный интерфейс; для Docker mod — ещё убрать `DOCKER_MODS` и пересоздать контейнер. Если WebUI сломан и в настройки не попасть, выключить опцию в `qBittorrent.conf` и перезапустить контейнер.

**Типографика**

| Элемент | Десктоп | Мобильная |
| --- | --- | --- |
| Базовый текст | Inter 12.5px / 400 | Inter 13px / 400 |

Имя торрента — 500, не 600: жирный Inter выглядит заметно крупнее соседнего текста.

**Размеры и радиусы.** Сайдбар 236px. Кнопки и поля в шапке 38px, в диалогах 36px. Строка таблицы — минимум 48px. Радиусы: чипы 6px, контролы 8–10px, карточки 12px, диалоги 16px, bottom sheet 18px сверху. Тап-зоны на мобильной — не меньше 44px.

**Компоненты**

- **Сегментированный прогресс** — главный элемент стиля: полоски 3px с зазором 2px (`repeating-linear-gradient`), пустая часть `--border`. Цвет: загрузка — акцент, раздача и готово — `--text-2`, пауза и очередь — `--dim`. Высота 12px в таблице, 14px в деталях, 10px на мобильной.
- **Статус** — иконка + текст в цвете статуса, без плашки. В карточке деталей статус — сплошной акцентный чип.
- **Кнопки**: основная (акцентный фон, текст `--bg`, 600), вторичная (рамка `--border`, фон `--card`), иконочная 32px без фона, опасная (`--danger-bg`).
- **Тумблер** 36×20 (мобильная 44×26): включён — акцент и тёмный кружок, выключен — #3F3F46 и светлый кружок.
- **Чекбокс** 15–16px, радиус 4px, отмечен — акцентная заливка.
- **Табы**: в карточках — подчёркивание 2px акцентом; переключатели режимов — сегмент-контрол на `--hover`.
- **Карта кусков** — сетка 10×10, зазор 2px: скачано — акцент, качается — #3F3F46, нет — `--border-subtle`.
- **Фокус** — кольцо 3px акцентом с прозрачностью 20% вокруг поля или кнопки.

## Экраны десктопа

Десктоп — от 768px. Основа: сайдбар слева, справа шапка, таблица торрентов и под ней карточка деталей выбранного торрента.

### Главный экран

**Сайдбар**

- Логотип «qBit».
- Фильтры по статусу со счётчиками: Все, Загрузка, Раздача, Завершено, Пауза (плюс «В очереди», «Ошибка» — только если такие есть). Активный — фон `--hover`, полоска акцента слева, счётчик на акценте.
- Под статусами — сворачиваемые группы «Категории» и «Теги» в том же стиле (в макете не нарисованы); показываются, только если в qBittorrent есть категории или теги.
- Внизу — карточка скорости: текущая загрузка крупно акцентом, спарклайн за последние 60 секунд, отдача и действующий лимит, тумблер «Альт. лимиты». Клик по карточке открывает диалог лимитов на вкладке «Глобальные».
- Пункт «Настройки».

**Шапка**: поиск по имени (горячая клавиша `/`), «Добавить торрент» (диалог на вкладке «Файл»), «Добавить magnet» (на вкладке «Magnet»), «Пауза для всех» (если всё на паузе — «Запустить все»).

**Таблица** в карточке, колонки: кнопка действия · Название + подстрока · Статус · Прогресс + % · Скорость · Размер. Опционально, выключено по умолчанию: «№ в очереди», Ratio, Добавлен. Сортировка кликом по заголовку, по умолчанию — по дате добавления, новые сверху.

Статусы qBittorrent сводятся к статусам интерфейса так:

| Состояния qBittorrent (`state`) | В интерфейсе | Кнопка в строке | Подстрока |
| --- | --- | --- | --- |
| downloading, forcedDL, metaDL | Скачивается (акцент) | Пауза | «N пиров · осталось X» |
| stalledDL | Скачивается | Пауза | «Ищет пиров» |
| uploading, forcedUP, stalledUP | Раздаётся (`--seed`) | Пауза | «N пиров · отдано X» |
| stoppedUP | Готово | Запустить раздачу | размер |
| stoppedDL | Пауза | Запустить | «X из Y» |
| queuedDL, queuedUP | В очереди (`--queue`) | Запустить принудительно | «Ждёт своей очереди» |
| checkingDL, checkingUP, checkingResumeData, moving | Проверка / Перемещение | — | прогресс проверки |
| error, missingFiles | Ошибка (`--danger`) | Перепроверить | текст ошибки |

**Выбор**: клик — выбрать строку и показать детали; Ctrl/Cmd и Shift — мультивыбор; при нескольких выбранных действия в шапке и меню применяются ко всем.

**Контекстное меню** (правый клик): Запустить / Пауза, Запустить принудительно, Ограничение скорости…, Категория ›, Теги ›, Очередь › (вверх, вниз, в начало, в конец), Последовательная загрузка, Сначала первые и последние части, Переместить…, Перепроверить, Переанонсировать, Скопировать magnet, Удалить….

### Карточка деталей

Показывается под таблицей, когда выбран один торрент; без выбора скрыта.

- Слева — карта кусков 10×10 (из `pieceStates`, сжатая до 100 ячеек: ячейка «скачана», если скачано больше половины её кусков; «качается», если есть куски в работе).
- Имя, чипы: статус (акцентный), число файлов, пиров, размер.
- Сегментированный прогресс и крупный процент.
- Иконки справа: Переместить (смена пути через `setLocation` — открыть папку на сервере браузер не может), вверх и вниз в очереди, Удалить. Кнопка «Приостановить» / «Возобновить».
- Строка статистики моноширинным: ↓ скорость, ↑ скорость, осталось, скачано X из Y, отдано.
- Вкладки:
  - **Файлы** — дерево папок; у файла чекбокс, путь (папка `--muted`, имя `--text`), размер, тонкая полоска прогресса и выпадашка приоритета: Не загружать (0), Обычный (1), Высокий (6), Максимальный (7). Снятая галка = «Не загружать», имя приглушается. Для папки — общий чекбокс и приоритет на всё содержимое.
  - **Трекеры** — таблица: адрес, статус (Работает / Обновляется / Ошибка / Отключён — точка + текст), сиды, пиры, скачали, сообщение. Строки DHT, PeX, LSD приглушены. Кнопка «Добавить трекер», удаление из меню строки.
  - **Пиры** — флаг страны (подсказка с названием), IP:порт, клиент, прогресс, ↓, ↑, получено, флаги. Сверху «N подключено · M в рое».
  - **Сведения** — путь, категория, теги, добавлен, завершён, хеш (копируется по клику), комментарий, создан, размер и число кусков, ratio, время раздачи, лимиты.

### Диалог «Добавить торрент»

- Сегмент «Файл .torrent / Magnet-ссылка».
- Файл: зона перетаскивания, несколько файлов сразу. Перетаскивание .torrent на любое место страницы тоже открывает диалог. Выбранные файлы — карточками с именем, размером, числом файлов и крестиком.
- Magnet: поле на несколько строк, по ссылке на строку.
- Папка сохранения (по умолчанию — из настроек или категории), категория (выбор с созданием новой), теги (чипы с автодополнением).
- Опции: Запустить сразу (вкл.), Последовательная загрузка, Сначала первые и последние части, Пропустить проверку хеша.
- Список файлов с чекбоксами (только для .torrent; файл разбирается в браузере). `torrents/add` не принимает выбор файлов, поэтому, если какие-то сняты: добавить остановленным, дождаться появления торрента по infohash, выставить `filePrio 0` снятым и запустить, если включено «Запустить сразу».
- Внизу: свободное место, «Отмена», «Добавить».

### Диалог «Ограничение скорости»

- Вкладки: Для торрента (для выбранных) / Глобальные / Альтернативные.
- Два поля, загрузка и отдача, в МБ/с с десятичными; под каждым быстрые кнопки ∞ · 1 · 5 · 10 · 50. Пусто или ∞ = без ограничения.
- Подсказка, если глобальный лимит ниже заданного для торрента.

### Диалог удаления

«Удалить торрент?» (или «Удалить N торрентов?»), имя, «Это нельзя отменить». Чекбокс «Удалить также скачанные файлы» с суммарным размером скачанного — всегда снят по умолчанию. Кнопки «Отмена» и красная «Удалить». Открывается и по клавише Delete.

### Настройки

Отдельная страница: сайдбар остаётся (активен пункт «Настройки»), слева список разделов, справа карточки. В шапке «Сбросить» и «Сохранить»; при несохранённых изменениях — подпись «Есть несохранённые изменения» и предупреждение при уходе со страницы.

| Раздел | Что внутри |
| --- | --- |
| Загрузки | папка по умолчанию, папка для незавершённых, добавлять на паузе, удалять .torrent после добавления, раздача (остановить при ratio, после времени) |
| Соединение | порт, UPnP, лимиты соединений и слотов |
| Скорость | глобальные и альтернативные лимиты, расписание альтернативных |
| BitTorrent | DHT, PeX, LSD, шифрование, анонимный режим, очередь (вкл., лимиты активных) |
| WebUI | логин и смена пароля, обход авторизации для localhost и подсетей, определять страны пиров |
| Внешний вид | акцентный цвет (хранится локально, не в qBittorrent) |

Лимиты в интерфейсе — в КБ/с или МБ/с, в API — байты/с; 0 = без ограничения.

### Вход

Карточка по центру: логотип, «Вход в qBit», адрес сервера моноширинным, логин, пароль с кнопкой «показать», «Войти», под карточкой — версия qBittorrent и WebAPI. Ошибка — красная плашка над кнопкой.

## Мобильная версия

Ниже 768px включается отдельная раскладка — экраны вместо панелей, крупные тап-зоны, действия внизу под большим пальцем.

- **Список.** Шапка: логотип, ↓ и ↑ скорость, кнопка альтернативных лимитов. Поиск во всю ширину, под ним чипы-фильтры с горизонтальной прокруткой. Торренты — в карточке строками: иконка статуса, имя, сегментированный прогресс с %, статус и скорость или размер. Снизу закреплены «Добавить торрент», иконка magnet и иконка настроек.
- **Действия со строкой.** Тап — экран торрента. Долгое нажатие — action sheet: Пауза / Запустить, Ограничение скорости, Категория, Удалить.
- **Экран торрента.** Шапка: «назад», «Переместить», «Удалить». Карта кусков, имя и чипы; карточка с прогрессом и сеткой 3×2 (загрузка, отдача, осталось, скачано, отдано, ratio). Вкладки Файлы / Трекеры / Пиры / Сведения — карточками-списками, без таблиц. Приоритет файла — кнопка справа, открывает action sheet. Внизу закреплена «Приостановить» / «Возобновить».
- **Добавить.** Bottom sheet поверх списка: сегмент «Файл / Magnet», поле ссылки, папка, категория, тумблеры опций, внизу «Отмена» и «Добавить».
- **Настройки.** Сгруппированный список (Сохранение, Скорость, Раздача, Ещё): строки с тумблером или значением и шевроном; тап по значению открывает экран или sheet редактирования. «Сохранить» в шапке.
- **Вход.** Та же карточка, что на десктопе, поля 44px.

**Обязательно для iOS**

- `html { -webkit-text-size-adjust: 100%; text-size-adjust: 100% }` — без этого Safari сам раздувает текст в широких блоках, и имена торрентов становятся огромными.
- Шрифт полей ввода — не меньше 16px, иначе Safari зумит страницу при фокусе.
- Отступы через `env(safe-area-inset-*)` и `viewport-fit=cover`: в браузере отступа сверху нет, в установленном PWA — ровно под чёлку и статус-бар.
- PWA: `manifest.json`, иконки, `display: standalone`, `theme-color: #09090B`.

## Работа с WebAPI

Всё идёт через `/api/v2` того же адреса: запросы с того же origin, cookie сессии подставляет браузер. Перед реализацией сверить параметры с [документацией WebAPI](<https://github.com/qbittorrent/qBittorrent/wiki/WebUI-API-(qBittorrent-5.0)>) для своей версии.

| Функция | Эндпоинты |
| --- | --- |
| Вход, выход | `auth/login`, `auth/logout` |
| Версии | `app/version`, `app/webapiVersion` |
| Список, счётчики, скорость, свободное место | `sync/maindata` (`server_state`: скорости, `free_space_on_disk`, `dht_nodes`, `use_alt_speed_limits`) |
| Пуск, пауза, «для всех» | `torrents/start`, `torrents/stop` (`hashes=a\|b` или `all`) |
| Удаление | `torrents/delete` (`deleteFiles`) |
| Добавление | `torrents/add` (multipart: `torrents`, `urls`, `savepath`, `category`, `tags`, `stopped`, `sequentialDownload`, `firstLastPiecePrio`, `skip_checking`) |
| Детали | `torrents/properties`, `torrents/files`, `torrents/trackers`, `torrents/pieceStates` |
| Пиры и страны | `sync/torrentPeers` (поля `country_code`, `country`) |
| Приоритет файлов | `torrents/filePrio` |
| Очередь | `torrents/increasePrio`, `decreasePrio`, `topPrio`, `bottomPrio` |
| Лимиты торрента | `torrents/setDownloadLimit`, `setUploadLimit` (байт/с, 0 = без лимита) |
| Глобальные и альт. лимиты | `transfer/setDownloadLimit`, `setUploadLimit`, `toggleSpeedLimitsMode` |
| Трекеры | `torrents/addTrackers`, `removeTrackers`, `reannounce` |
| Прочие действия | `setLocation`, `setCategory`, `createCategory`, `addTags`, `removeTags`, `toggleSequentialDownload`, `toggleFirstLastPiecePrio`, `recheck`, `setForceStart` |
| Настройки | `app/preferences`, `app/setPreferences` (`json=…`, только изменённые ключи) |

**Обновление данных**

- `sync/maindata?rid=N` раз в секунду. Ответ инкрементальный: слить `torrents` (только изменённые поля), удалить `torrents_removed`, обновить категории, теги и `server_state`; при `full_update: true` — заменить всё.
- Для выбранного торрента и открытой вкладки: свойства, файлы и куски — раз в 2 с, пиры (`sync/torrentPeers`, тоже инкрементально) — раз в 2 с, трекеры — раз в 5 с. Закрытые вкладки не опрашиваются.
- Когда вкладка браузера скрыта (`document.hidden`), опрос замедляется до раза в 10 с.
- История для спарклайна копится в памяти, 60 точек; после перезагрузки начинается заново — в API истории скоростей нет.
- Ответ 403 на любой запрос — сессия истекла, перейти на экран входа.

**Только 5.x.** Используются эндпоинты WebAPI 2.11+: `torrents/start` и `torrents/stop`, `stopped` в `torrents/add`, состояния `stoppedDL`/`stoppedUP`. При запуске проверить `app/webapiVersion`: ниже 2.11 — вместо интерфейса экран «Нужен qBittorrent 5.0 или новее» с текущей версией.

**Единицы.** Размеры и скорости — по основанию 1024, подписи Б, КБ, МБ, ГБ, ТБ; скорость — «/с». Число со знаками: до 10 — два знака после запятой, до 100 — один, дальше без дробной части.

## Вход и сессия

Сессию полностью ведёт qBittorrent через cookie; WebUI пароли не хранит и сам токенов не держит.

1. При запуске запросить `app/version`. 200 — сразу открыть интерфейс (включён обход авторизации для localhost или подсети). 403 — показать экран входа.
2. Вход: `POST auth/login`, `username` и `password` как `application/x-www-form-urlencoded`. Тело `Ok.` — успех; `Fails.` — «Неверный логин или пароль»; 403 — IP заблокирован после неудачных попыток: «Слишком много попыток, вход временно заблокирован».
3. Поля с `autocomplete="username"` и `"current-password"`, форма отправляется по Enter — чтобы работали менеджеры паролей.
4. Выход — пункт в настройках: `auth/logout` и возврат на экран входа.
5. Истёкшая сессия (403 на любом запросе) — вернуть на вход, после входа восстановить открытый экран.

## Нефункциональные требования

- **Производительность.** 1000+ торрентов без подтормаживаний: виртуализированный список, мемоизированные строки, обновляются только изменившиеся. Бандл без шрифтов и флагов — до 300 КБ gzip; флаги подгружаются по требованию.
- **Клавиатура.** ↑/↓ — по строкам, Enter — детали, Пробел — пауза/пуск, Delete — удаление, `/` — поиск, Esc — закрыть диалог. Фокус всегда видим.
- **Доступность.** Настоящие `<button>`, `<input>`, `<label>`; `aria-label` у иконочных кнопок; контраст текста не ниже 4.5:1; статусы различаются не только цветом, но и иконкой с текстом.
- **Состояния.** Пустой список («Торрентов пока нет» + «Добавить»), ничего не найдено по поиску или фильтру, потеря связи с qBittorrent (плашка «Нет соединения, повторяем…» и автоповтор), ошибки действий — тост внизу.
- **Браузеры.** Последние две версии Chrome, Firefox, Safari; iOS 16+.
- **Язык.** Только русский, но все строки — в одном файле, чтобы позже добавить английский.
- **Приватность.** Ни аналитики, ни внешних запросов.

## Этапы и критерии готовности

Делать по этапам; каждый заканчивается рабочей сборкой, которую можно положить в qBittorrent и проверить.

1. **Каркас.** Проект, токены и шрифты, API-клиент с проверкой версии, вход, `sync/maindata`, сайдбар с фильтрами и карточкой скорости, таблица с поиском и сортировкой. Готово, когда: через альтернативный WebUI в Docker можно войти и список обновляется каждую секунду.
2. **Действия.** Пуск и пауза, «для всех», мультивыбор, контекстное меню, удаление, добавление файла и magnet, диалог лимитов, альтернативные лимиты.
3. **Детали.** Карточка с картой кусков, вкладки «Файлы» с приоритетами, «Трекеры», «Пиры» с флагами, «Сведения»; очередь.
4. **Настройки.** Все разделы, сохранение только изменённого, выход.
5. **Мобильная версия.** Все мобильные экраны, safe areas, PWA.
6. **Полировка.** Горячие клавиши, пустые и ошибочные состояния, проверка на 1000+ торрентов, README.
